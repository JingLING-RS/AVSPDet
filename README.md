# AVSPDet

Project repository for **Asymmetric Visual Perception and Image-Conditioned Semantic Prompting for Tiny Object Detection in Low-Altitude Aerial Imagery**.

AVSPDet is a tiny object detection framework for low-altitude aerial imagery. It combines asymmetric visual perception, image-conditioned semantic prompting, and scale-aware head reconfiguration.

## Code availability

The source code will be made publicly available in this repository upon publication of the paper.

At present, this repository contains the project description only. Implementation files are not yet available.
